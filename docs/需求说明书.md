## 1. 引言

### 1.1 编写目的

本文档描述一款运行于 Android 设备上的简易文档阅读/编辑器——中文名「简记」，英文名 Sample Note（以下简称"本软件"）——的功能与非功能需求，作为软件设计、开发与验收的依据。

### 1.2 项目背景与目标

用户需要一款轻量级的文档工具，能够：

- 阅读 epub、xml、md、txt 格式的文件；
- 编辑 md、txt 格式的纯文本文件；
- 阅读时支持"写满一行后自动换行"与"不换行（横向滚动查看）"两种排版方式；
- 阅读与编辑状态下字号大小、行距适中、可调。

目标是实现简单可靠，不追求专业阅读器/IDE 级别的功能。

### 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| 自动换行模式 | 文本到达屏幕右边界后自动折到下一行，无水平滚动条 |
| 不换行模式 | 一行文本完整显示在单行内，超出屏幕的部分通过左右滑动查看 |
| SAF | Storage Access Framework，Android 系统提供的文件访问框架 |
| epub | 一种基于 ZIP + XHTML 的电子书格式（含 epub2/NCX 与 epub3/nav.xhtml 两种导航） |

## 2. 整体描述

### 2.1 产品定位

面向个人用户的轻量本地文档工具，无网络依赖、无账号体系，所有数据保存在设备本地。

### 2.2 用户特征

需要在手机/平板上查看电子书、纯文本笔记、日志或简单标记文档，并对 md/txt 做快速修改的用户。

### 2.3 运行环境

- 操作系统：Android 8.0（API 26）及以上
- 设备形态：手机为主，兼容平板横竖屏
- 开发技术栈：Kotlin 原生（Jetpack Compose）

### 2.4 假设与约束

- epub 以**纯文本 + 图片 + 基本样式**方式渲染：解析章节（spine）顺序，抽取正文文本与插图（`<img>`，按屏宽等比缩放显示，加载失败/格式不支持显示占位提示），提取并显示封面图（svg 内嵌单张图片），应用 CSS 基本文字样式子集（字号/字重/斜体/文字颜色/对齐/段间距/行距；忽略 `font-family` 与复杂布局属性，样式以阅读器全局设置为兜底）；不保留页内链接与完整 CSS 布局；兼容 epub2（NCX）与 epub3（nav.xhtml，含 NCX 回退）导航。**渲染范围边界（REV10，用户 2026-09-13 指示）**：本期 epub 渲染以「章节标题与正文可区分、内容完整可读」为目标，**不追求书样式保真**——CSS 子集（F2.15）与默认标题层级（F2.17）即终态：不因个别书的观感追加新属性/新选择器、不加载外链样式表（`<link rel="stylesheet">`/manifest `.css`）；书中未使用 `h1`~`h6` 标签（如 Calibre 产出以 `<p class="…">` 表达标题）时，标题与正文可以不作区分。
- md/txt 以**纯文本（源码）方式编辑**，类似记事本，不做所见即所得；md 提供只读的简单预览。
- xml 仅做阅读（可选语法高亮），不支持编辑。
- 应用不内置书城/下载功能，仅打开设备本地文件。

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| F2.1 | 支持打开 epub、xml、md、txt 文件并展示文本内容 | 高 |
| F2.2 | 支持**自动换行**与**不换行（横向滚动）**两种阅读排版方式，可在阅读界面一键切换；切换不丢失当前阅读位置（尽量定位到原偏移附近） | 高 |
| F2.3 | 字号可调（建议档位：12/14/16/18/20/22/24 sp，默认 16 sp），行距可调（建议档位：1.2/1.5/1.8/2.0 倍，默认 1.5 倍）；设置持久化 | 高 |
| F2.4 | 字体方案：默认"代码风格"——英文/数字优先使用系统等宽字体（程序编辑器风格），中文使用系统默认中文字体（等线风格，系统自动回退）；另提供 衬线 / 无衬线 两种整体字体族可选；支持通过 SAF 导入自定义 ttf/otf 字体文件（如用户自备的等线字体）。选择即时生效并持久化 | 高 |
| F2.5 | 阅读主题（前景/背景成对搭配）预设可选：默认白、护眼绿（豆沙绿背景）、柔光米黄（暖黄低亮度背景）、夜间黑（深色背景浅灰字）；阅读界面一键切换，即时生效并持久化 | 高 |
| F2.6 | 打开 txt 文件自动探测编码（覆盖 UTF-8、UTF-16LE/BE、GBK，Latin-1 兜底），可手动切换 | 高 |
| F2.7 | epub 按章节组织，提供章节列表跳转（兼容 epub2 NCX 与 epub3 nav.xhtml 导航） | 高 |
| F2.8 | 阅读进度记录与恢复：再次打开同一文件时回到上次位置 | 中 |
| F2.9 | md 文件提供只读渲染预览（标题、列表、加粗/斜体、代码块等基本元素），与源码视图可切换 | 中 |
| F2.10 | xml 文件按纯文本展示（可选：简单语法高亮） | 低 |
| F2.11 | 阅读主题与系统深色/浅色模式联动：未手动选择主题时跟随系统（浅色=默认白，深色=夜间黑）；手动选择后以用户选择为准 | 中 |
| F2.12 | 阅读界面支持长按选择文本并复制（含 epub/txt/md/xml 各格式） | 高 |
| F2.13 | md 文件提供目录（大纲）展示与跳转：按标题层级（H1~H6）列出目录项，点击跳转到对应标题位置；目录提取须跳过代码块内的标题样式文本（代码注释不得误判为标题）；源码视图与预览视图均可使用；目录条目标题剥除行内标记（加粗/斜体/行内代码/链接——链接保留链接文字、去除 URL 与地址） | 中 |
| F2.14 | epub 正文插图与封面图显示：正文 `<img>` 插图按屏宽等比缩放显示（防大图 OOM，懒加载），图片加载失败或格式不支持时显示占位提示、不崩溃；**svg 一律不直接渲染**（矢量图统一走占位提示），封面图按 OPF 声明提取——`<meta name="cover">` 或 manifest `properties="cover-image"` 指向的**位图**（svg 封面仅当其内嵌位图引用时提取）按屏宽显示；图片不可用不阻塞正文阅读；图片与占位提示均提供语义描述（alt 作为无障碍内容描述） | 中 |
| F2.15 | epub 基本 CSS 文字样式渲染：应用 CSS 子集（字号/字重/斜体/文字颜色/对齐/段间距/行距），不支持的样式属性与选择器一律忽略；**合并规则**：阅读器全局设置（字号/行距/字体/主题）为绝对基准，CSS 字号/行距仅作为相对倍率（clamp 0.5~3.0）叠加，字重/斜体/对齐直接采用，CSS 文字颜色与当前主题背景对比度不足 4.5:1 时回退主题前景色；任何书不因样式解析失败而不可读 | 低 |
| F2.16 | epub 目录**原样呈现**与锚点跳转：目录面板直接呈现文件自带目录（epub3 nav.xhtml 优先，epub2 NCX 回退）的条目、标题与层级（均为文件作者原样），**不按 spine 生成兜底条目**（取消「第 N 章」），文件无目录则不提供目录入口；点击目录条目跳转到锚点（file.xhtml#anchor）所在段落（锚点落在非段落元素时取最近前段落；正文解析降级路径无锚点信息时退化为章首）；当前章节无对应目录条目时顶栏标题**留空**，不编造章节名 | 高 |
| F2.17 | epub 章节**标题层级排版**：对书内 `h1`~`h6` 标题段落，书未通过 CSS 声明该标题字号时，按阅读器默认标题层级比例（相对全局字号、逐级递减，H1~H6 约 1.6/1.45/1.3/1.2/1.1/1.05 倍）渲染并加粗，使标题与正文、各级标题之间**可辨**；书 CSS 已声明该标题字号时**以书 CSS 为准**（不与默认比例相乘），加粗同理（未声明→默认加粗；显式声明 bold/normal→遵循）；默认层级属阅读器侧 UA 默认样式子集，仅作用于 epub 标题段落，不改变「全局设置为绝对基准 + CSS 仅相对偏移」的既有合并规则（F2.15）与对比度回退、段距行为；md 预览/源码视图与正文段落样式不受影响；无标题书零影响、任何书不因该能力不可读 | 中 |

## 4. 非功能需求

| 类别 | 需求 |

## 6. 验收标准（摘要）

1. 分别打开 epub（epub2/epub3 各一）/xml/md/txt 示例文件，内容完整显示，无乱码（UTF-8/UTF-16/GBK 各一例）。
2. 阅读界面可在自动换行 / 不换行（横向滚动）之间切换，且字号、行距调节即时生效并持久保存。
3. 阅读主题切换（默认白/护眼绿/柔光米黄/夜间黑）与字体切换（代码风格/衬线/无衬线/导入自定义字体）即时生效，重启应用后保持。
4. 阅读界面可长按选择并复制文本。
5. 对 md/txt 文件进行修改并保存，重新打开后内容一致；未保存退出时出现提示。
6. epub 文件可通过章节列表跳转到指定章节。
7. 在 API 26 模拟器与一台主流新系统真机上安装运行上述用例，无崩溃。
8. md 文件可通过目录跳转到指定标题位置：目录层级（H1~H6）正确、代码块内标题样式文本不出现、源码与预览视图点击定位准确。
9. 打开含图 epub，正文插图按屏宽正常显示且缩放合理、封面图显示；损坏或不支持格式的图片显示占位提示，不崩溃、不影响正文阅读；带基本 CSS 样式的章节（字号/字重/颜色/对齐等）渲染生效，样式解析失败的书仍可读。
10. epub 目录呈现文件自带目录（标题/层级原样，无目录文件不显示目录入口、无「第 N 章」兜底条目），点击目录条目定位到锚点段落（《邓小平文选》中「出版说明」等未编入 NCX 的章节顶栏不显示编造章名）；阅读流可跨章连续滚动（开头滑到结尾）；右缘进度条指示全书进度并可拖动跳转。
11. epub 章节标题层级可辨：打开书内 `h1`~`h6` 齐全且未声明标题字号的书，各级标题相对正文与相邻层级均可区分（默认层级比例生效）；书 CSS 显式声明标题字号的书以书 CSS 为准（不被默认比例覆盖或叠加放大）；既有书籍（含真 CSS 书）不因该能力出现乱版或不可读。
