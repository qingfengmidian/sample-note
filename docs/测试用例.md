## 0. 说明

- 用例编号规则：`TC-<模块>-<序号>`，模块与需求章节对应（F1 文件访问 / F2 阅读器 / F3 编辑器 / F4 通用 / NF 非功能）。
- 优先级：P0 = 必须通过（验收阻塞）；P1 = 重要；P2 = 一般。
- 执行环境：API 26 模拟器 + 一台主流新系统真机（如 API 33/34）。
- 测试数据准备（fixtures）：
  - `sample_utf8.txt`（UTF-8 无 BOM，中英文混排，含超长行）
  - `sample_gbk.txt`（GBK 编码中文）
  - `sample_bom.txt`（UTF-8 带 BOM）
  - `sample.md`（含标题/列表/加粗斜体/代码块/引用）
  - `sample.xml`（嵌套层级 ≥ 3）
  - `sample.epub`（≥ 3 章，含 NCX；正文含图片标签，验证图片被忽略）
  - `broken.epub`（缺 OPF / 缺 NCX 各一份）
  - `large.txt`（约 8 MB）、`huge.txt`（约 15 MB）
  - `DengXian.ttf`（测试机自备的等线字体文件）与一个损坏的 `bad.ttf`
