## 0. 说明

- 用例编号规则：`TC-<模块>-<序号>`，模块与需求章节对应（F1 文件访问 / F2 阅读器 / F3 编辑器 / F4 通用）；自动化用例分 `TC-UT-*`（单元）与 `TC-UI-*`（Compose UI）。
- 优先级：P0 = 必须通过（验收阻塞）；P1 = 重要；P2 = 一般。
- 执行环境：API 26 模拟器 + 一台主流新系统真机（如 API 33/34）。
- 颜色断言约定：涉及主题色值的断言统一表述为"与设计文档 3.1 节 `ReadingTheme` 对应枚举值一致"，不在用例中写死魔数。
- 测试数据准备（fixtures）：
  - `sample_utf8.txt`（UTF-8 无 BOM，中英文混排，含超长行——单行 ≥ 500 字符）
  - `sample_gbk.txt`（GBK 编码中文，**含 GBK 特有字符如"镕"**，防止按 GB2312 子集误判）
  - `sample_latin1.txt`（Latin-1/ISO 8859-1 编码，含 é、ü 等西欧特殊字符）
  - `sample_utf16le.txt` / `sample_utf16be.txt`（UTF-16 LE/BE 带 BOM）
  - `sample_bom.txt`（UTF-8 带 BOM）
  - `sample.md`（含标题/列表/加粗斜体/代码块/引用）
  - `sample.xml`（嵌套层级 ≥ 3）
  - `sample.epub`（epub2，NCX 导航，≥ 3 章；正文含图片标签，M11 起验证占位/渲染行为，见 TC-F2-17）
  - `sample3.epub`（epub3，nav.xhtml 导航，≥ 3 章）
  - `hybrid.epub`（epub3 nav.xhtml 与 NCX **并存**，且两者章节标题刻意不同，用于验证优先级）
  - `many_chapters.epub`（> 100 章）
  - `nested_toc.epub`（嵌套目录 > 3 级）
  - `mixed_encoding.epub`（内嵌 XHTML 声明 GBK）与 `bad_decl.epub`（XHTML 声明 UTF-8 但实际为 GBK 字节流，负例）
  - `broken.epub`（缺 OPF / 缺导航文件各一份）
  - M11 新增（F2.14/F2.15）：`sample_images.epub`（正文含 png/jpg 位图 + 一张 svg）、`sample_cover.epub`（OPF `meta name="cover"` 指向位图封面）、`broken_image.epub`（img 引用缺失条目 + 截断位图）、`styled.epub`（内联 style + `<style>` 规则覆盖字重/斜体/对齐/颜色/相对字号）、`bad_css.epub`（样式表含非法语法）——均由 FixtureGenerator 生成，图片用程序生成的小位图
  - M11 新增（F2.13）：`sample_toc.md`（多级 ATX 标题混合正文/列表/围栏代码块，代码块内含 `#` 注释行）
  - `large.txt`（约 8 MB）、`huge.txt`（约 15 MB）
  - `user_font.ttf`（**测试人员自备的任意合法 ttf/otf 字体文件**，如从本机系统提取的字体；项目仓库不分发任何商业字体文件）与损坏的 `bad.ttf`
